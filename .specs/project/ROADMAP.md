# Roadmap

**Current Milestone:** M1 工程基线与生产可交付性
**Status:** IN PROGRESS

## M0 Current Baseline

**Goal:** 明确当前项目能力和风险，形成后续执行地图。
**Target:** 已完成初次盘点并通过当前构建基线。

### Features

**核心论坛能力** - COMPLETE

- 注册、登录、退出、当前用户查询。
- 帖子列表、详情、发布、草稿、搜索、标签、分类、粉丝可见、关闭评论。
- 评论、点赞、收藏、关注、浏览历史、通知、私信。

**社区治理能力** - COMPLETE

- 举报、后台处理、敏感词、禁言、封禁、角色管理、审计日志。

**基础交付能力** - PARTIAL

- Docker Compose、Nginx、GitHub Actions 构建和部署配置已存在。
- 仍缺数据库迁移、API 文档依赖、观测、回滚说明和完整测试矩阵。

## M1 工程基线与生产可交付性

**Goal:** 让项目从“能跑”变成“能持续交付”。
**Target:** CI 可稳定阻止核心回归，数据库结构可版本化演进，生产部署有最小可运维能力。

### Features

**数据库迁移治理** - COMPLETE

- 已引入 Flyway。
- 已新增 `V1__init_schema.sql` 管理当前完整 schema。
- 已新增 `V2__ensure_post_publish_settings.sql` 替代旧的 `alter_post_settings.sql` 手动补丁。
- 已在临时 MySQL 8.0.44 实例上验证新库初始化和老库补丁路径。

**测试基线扩展** - PLANNED

- 后端增加认证、权限、帖子、评论、点赞、后台审核的集成测试。
- 前端增加类型检查脚本和关键页面 smoke tests。
- CI 加入测试、构建、类型检查和必要缓存。

**API 文档与契约** - PLANNED

- 添加 OpenAPI 文档能力。
- 文档覆盖认证、帖子、评论、通知、后台、上传。
- 对统一响应 `R<T>` 和分页结构做约定说明。

**配置与部署治理** - PLANNED

- 整理 `.env.example`、生产环境变量、Cookie、CORS、Redis 密码和 OSS 配置。
- 修正 CI/CD 中分支和镜像发布的一致性问题。
- 增加部署、备份、回滚、日志查看说明。

**可观测性** - PLANNED

- 引入 Actuator 健康检查。
- 规范日志级别，关闭生产 SQL stdout。
- 预留指标和错误排查入口。

## M2 核心业务可靠性

**Goal:** 核心互动链路在并发、重复请求和异常场景下保持数据一致。

### Features

**互动计数一致性** - PLANNED

- 点赞、评论、收藏、关注、浏览、积分使用事务和原子更新。
- 补充重复点赞、重复评论、并发取消等测试。

**服务层边界整理** - PLANNED

- 将 Controller 中的主要业务规则下沉到 Service。
- 统一鉴权、作者校验、禁言、敏感词和可见性判断。

**通知与消息可靠性** - PLANNED

- 明确通知类型枚举。
- 处理 WebSocket 在线推送和离线通知一致性。
- 私信已读、会话列表、未读数加入测试。

## M3 安全与治理强化

**Goal:** 面向真实社区运营建立更完整的安全和审核机制。

### Features

**认证安全强化** - PLANNED

- 明确 Cookie SameSite、Secure、CSRF 策略。
- 登录注册限流增加降级和异常处理测试。
- JWT 密钥长度、过期、黑名单策略文档化。

**内容治理强化** - PLANNED

- 举报处理联动内容状态。
- 敏感词策略从简单命中升级为可配置策略。
- 审计日志覆盖所有高风险操作。

**文件上传安全** - PLANNED

- MIME、扩展名、大小、对象键、OSS 权限和下载 URL 策略统一。
- 本地上传和 OSS 分片上传边界清晰化。

## M4 产品体验与运营能力

**Goal:** 提升用户体验、运营效率和社区增长能力。

### Features

**前端体验完善** - PLANNED

- 首页、搜索、帖子详情、发布、个人中心、后台页面做移动端和异常态验证。
- 统一空态、加载态、错误态。

**运营看板** - PLANNED

- 用户、内容、举报、增长、活跃、积分统计。
- 管理后台分页、筛选、导出和审计查询增强。

**内容发现** - PLANNED

- 热门、精华、相关帖子、关注流和标签页优化。

## Future Considerations

- 全文搜索引擎，如 Elasticsearch 或 Meilisearch。
- 对象存储 CDN、图片处理和内容安全检测。
- 消息队列，用于通知、积分、审计和异步任务。
- 多环境 IaC、Kubernetes 或云托管部署。
- 多租户和企业空间。
